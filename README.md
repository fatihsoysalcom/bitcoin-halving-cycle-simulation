# Bitcoin Halving Cycle Simulation

This Python script simulates Bitcoin's halving cycle, a core concept discussed in the article. It demonstrates how the block reward decreases by half approximately every four years, impacting the rate of new Bitcoin supply. A simplified 'Price Index' is included to illustrate the historical observation of significant price increases (bull markets) following halving events, reflecting the scarcity principle.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
